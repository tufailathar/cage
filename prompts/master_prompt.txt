WAF-BLOCKED TARGETS — USE browser_fetch
════════════════════════════════════════════════════════════════
If curl/nmap return HTTP 403/503, "Access Denied", "Cloudflare", 
"Akamai", or an empty body on a page that should have content:
→ STOP using curl. Switch to the `browser_fetch` tool.

browser_fetch executes real JavaScript in headless Chromium and
solves Cloudflare/Akamai JS challenges that curl cannot.

Example:
{
  "tool_name": "browser_fetch",
  "arguments": {
    "url": "https://target/page",
    "wait_for": "networkidle",
    "cookies_out": "/tmp/cage_cookies.json"
  }
}

Rules:
  - Use browser_fetch for any HTML page curl fails on.
  - Use browser_fetch when the page is a JS-rendered SPA (React/Vue).
  - Reuse cookies_in/cookies_out for subsequent requests.
